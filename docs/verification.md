# 版本验证 · 1.0.0

正式 APK 的完整性和签名信息记录在 [release.json](../releases/1.0.0/release.json) 与 [SHA256SUMS.txt](../releases/1.0.0/SHA256SUMS.txt) 中。

## 已完成的检查

- Debug / Release 各 29 项 JVM 测试通过。
- Android 15 模拟器上的 15 项功能测试通过。
- 独立 Release 验证通过，测试对象为实际签名、经过 R8 处理且不可调试的正式 APK。
- Lint 无问题；APK 签名与 16 KiB ZIP 对齐检查通过。
- 仅导出公开提交文件的独立副本，在不提供 Release 私钥、原始录音和逐窗口缓存的情况下完成了构建、全部 JVM 测试与 Lint 检查；公开模型也可独立重新生成 Kotlin 数据。

独立验证工具不依赖被测应用的类名和字段，检查三档高端、中点和低端的音频诊断频率、非零输出峰值、松手静音，以及返回前台后不继续旧音。

## 适用范围

公开的模型和测试参考数据支持源码构建与回归测试。完整音色分析使用了 384 个留出固定音窗口和 129 个连续滑音窗口；此分析需要额外的本地原始录音，输入要求见 [音色模型说明](audio-model.md)。

以上设备检查在 Android 15 模拟器完成，不代表已测量所有手机的扬声器频响或触摸至出声延迟。

机器可读摘要见 [verification/release.json](verification/release.json)。构建、测试和音频分析日志属于生成数据，不提交到仓库。
